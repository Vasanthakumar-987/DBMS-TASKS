# Task V – Payment Transaction Management System

## Objective
Design and implement a Payment Transaction Management System for the Amazon E-Commerce Database project.

## Requirements Covered
1. Create the `Payment` table.
2. Store payment mode, payment date, amount and transaction status.
3. Manage successful and failed transactions.
4. Analyze payment methods used by customers.
5. Generate payment transaction reports.

## SQL File
See `payment_transaction_management.sql` for table creation, sample transactions, updates, payment-method analysis and transaction reports.
