# Task VI – Product Review and Rating Management System

## Objective
Design and implement a Product Review and Rating Management System for the Amazon E-Commerce Database project.

## Requirements Covered
1. Create `Review` and `Rating` tables.
2. Store customer feedback and ratings.
3. Retrieve product review details.
4. Calculate average product ratings using aggregate functions.
5. Identify highly rated products.

## Tables
- `Review` – stores customer feedback for products.
- `Rating` – stores numerical ratings for reviews.
- `Customers` and `Products` – supporting entities used for reporting.

## SQL File
See `product_review_rating_management.sql` for table creation, sample reviews, review retrieval, aggregate rating analysis and highly rated product queries.
